# Open Cyberpunk MMORPG

> **An open-source persistent cyberpunk world built with Unreal Engine 5.**

**Open Cyberpunk MMORPG** is an experimental open-source project exploring what a persistent, player-driven cyberpunk MMO can become.

Instead of building a world primarily around predefined quests and scripted content, the project focuses on interconnected systems that allow players and communities to shape the world through their actions.

## Vision

We want to create a cyberpunk world that feels persistent, dynamic and worth exploring.

A world where:

- player actions have consequences;
- communities can influence how the world develops;
- physical and digital systems interact;
- the economy is shaped by players;
- the environment changes over time;
- history is created through gameplay rather than only through scripts;
- exploration continues beyond what is immediately visible.

> **Systems create possibilities. Players create stories.**

## Core Principles

### Persistent World

The world should remember meaningful events and continue evolving over time.

### Player-Driven Gameplay

Players should have tools for creating their own goals, organizations, economies and conflicts instead of depending entirely on predefined content.

### Systemic Design

Gameplay systems should interact with each other and create emergent situations.

### Physical + Digital World

Cyberpunk is not only a visual style.

Technology, infrastructure, networks and the physical world should form parts of the same simulation.

### Open Development

The project is developed publicly and is intended to support community contributions, modding and experimentation.

### MMORPG From the Beginning

Multiplayer, dedicated servers, persistence and server-authoritative simulation are architectural requirements rather than features to be added after the game is built.

## Technology

- **Engine:** Unreal Engine 5
- **Core:** C++ / Unreal Engine
- **Networking:** Dedicated authoritative servers
- **Development:** Git / GitHub
- **Model:** Open-source development
- **Initial target:** PC

The architecture will evolve as prototypes validate the design.

## Development Strategy

The project starts small.

Instead of attempting to build an entire cyberpunk metropolis immediately, development will begin with a minimal persistent multiplayer environment and expand incrementally.

Each development stage should prove a small part of the larger architecture.

Automated testing, reproducible development workflows and clear architectural boundaries are important from the beginning.

## Open Source

The project is intended to allow developers, artists, designers, testers and modders to participate in development.

As the foundation matures, the repository will provide:

- contribution guidelines;

- coding standards;

- issue and proposal workflows;
- testing infrastructure;
- modding interfaces.
